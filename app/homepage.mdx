# Blog app

Welcome to the blog app. This application is built with Next.js as part of the [Full Stack Open: Next.js](https://fullstackopen.com/en/part0/general_info) course.

## Blogs

You can browse the blogs, read individual blog posts, and like them. Registered users can create new blogs, build a reading list, and generate an API token for their own use.
